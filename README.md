A complete story in exactly six words, written by a small Python program for make.fun's "Six Words, One Story" bounty.

> She planted tulips. He never returned.

Six words, one whole arc: planting as hope for a shared future, "never returned" as the turn that closes it. Who he is, why he left, and whether she is still waiting are left for the reader to fill in.

## Run it

```sh
python3 main.py
```

The program writes the story to `/output/entry.txt` (exactly six words, 36 characters) and validates the word count and length before writing.
